# RepoMedic

RepoMedic is an automated incident command and root cause analysis tool designed to diagnose system failures.

Status: Early development (Phase 0)

## Getting Started
Please refer to [docs/development.md](docs/development.md) for full instructions on setting up and running the database, backend, and frontend locally.

## Project Structure
- **/backend**: FastAPI application managing APIs and database interactions.
- **/frontend**: Next.js App Router providing the user interface.
- **/docs**: Project documentation and setup guides.
